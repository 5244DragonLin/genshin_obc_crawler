# 字段说明

26 类图鉴 JSON 的键名一览。顶层结构与公共字段在前，各分类专有字段在后。

前六类（角色 / 武器 / 圣遗物 / 敌人 / 食物 / 书籍）信息密度高，各有专用键名；
其余 20 类走统一结构，见最后的「通用图鉴」一节。

## 通用约定

- **英文键**是项目自己定的语义化键名，含义固定，跨版本不变；**中文键**是观测枢词条原文的表格行标题，原样保留，随站点内容变化，不做翻译。
- 标题带「预告」的未上线词条（如「米提亚【预告】」）正文全是「待更新」占位，直接跳过不导出，不占条目数。影音回廊频道的「角色预告 PV」是正经片名，不适用这条规则。
- 可选键在数据不存在时**整个键不出现**，不会写成 `null` 或空串（`cover` 例外，见下）。
- 站点上一格能挂多个标签的字段（敌人的元素、食物的菜系、书籍的获取方式），产物一律给数组，只有一个值时也是单元素数组。
- 图片字段分两类：`icon` / `portrait` / `image` / `audio` 是站点原始 URL；`cover` 是落盘后的相对路径，分隔符随操作系统。
- 文本字段里的换行原样保留（`\n`），未做 HTML 转义。

## 文件级

`角色图鉴.json` / `武器图鉴.json` / `圣遗物图鉴.json` / `敌人图鉴.json` / `食物图鉴.json` / `书籍图鉴.json` 六者结构一致，其余 20 类同构：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `catalog` | string | 分类中文名，如「敌人图鉴」 |
| `count` | int | 本分类条目数，等于 `items` 数组长度 |
| `generated_at` | string | 生成时间，`YYYY-MM-DD HH:MM:SS` 本地时区 |
| `items` | array | 条目数组。角色、武器、食物按稀有度降序、同稀有度按名称排；圣遗物 `rarity` 是文本，敌人与书籍没有 `rarity`，这三类只按名称排 |

`manifest.json`：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `checked_at` | string | 本轮检查时间 |
| `generated_at` | string | 产物生成时间 |
| `catalogs` | array | 各分类的 `key`、`name`、`count`、`file`（产物文件名，未重写时带「（未变）」后缀）、`failed`（失败明细数组） |

`changes.json`：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `checked_at` | string | 本轮检查时间 |
| `totals` | object | 全分类汇总，键见下 |
| `catalogs` | array | 各分类明细，每项带 `key`、`name` 与同样的计数键 |

计数键：`added` 新增、`updated` 更新、`removed` 移除、`failed` 失败、`unchanged` 未变、`skipped` 跳过。

## 角色

### 基础

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id，可用于拼 `url` |
| `name` | string | 角色名，取词条正文的正式名 |
| `card_name` | string | 列表卡片上的标题。**仅当与 `name` 不同才出现**，典型是旅行者：`name` 为「旅行者（空）」、`card_name` 为「旅行者·冰」 |
| `url` | string | 观测枢词条页地址 |
| `summary` | string | 一句话简介 |
| `alias` | string | 别名 / 曾用名。站点未提供该字段，实际数据中不出现 |
| `region` | string | 地区，如「璃月港」 |
| `element` | string | 元素，如「冰」 |
| `weapon_type` | string | 武器类型，如「弓」 |
| `rarity` | int | 稀有度星级，4 或 5；两个「奇偶」词条站点给 0 |
| `icon` | string | 列表页头像原始地址（196×196）。**不再下载到本地**，仅保留地址 |
| `portrait` | string | 立绘原始地址，取词条「角色展示」面板里唯一的静态图 |
| `cover` | string，可为 null | 立绘落盘后的相对路径。**唯一会显式为 `null` 的键**：两个「奇偶」词条没有立绘时为 `null` |

### basic：档案

中文键，取值直接来自词条档案面板，常见键：

| 键 | 含义 |
| --- | --- |
| `生日` | 角色生日，如「12月2日」 |
| `所属` | 所属组织 / 势力 |
| `定位` | 玩法定位，如「冰元素输出型角色」 |
| `武器类型` | 与顶层 `weapon_type` 同值，此处为原文写法 |
| `命之座` | 命之座名称，如「仙麟座」 |
| `称号` | 角色称号 |
| `角色定位` | 少数角色（千星奇域的两个「奇偶」）用这个键代替 `定位` |
| `神之眼` | 神之眼属性。旅行者 14 条与「奇偶」2 条为「无」，北斗、辛焱、香菱为对应元素名 |

### cv：配音

四个中文键，值为配音演员名（原文含非拉丁名时会带括号注音）。134 条角色四个都有，2 个「奇偶」词条站点没给 CV、无此键：

| 键 | 含义 |
| --- | --- |
| `中` | 汉语 CV |
| `日` | 日语 CV |
| `英` | 英语 CV |
| `韩` | 韩语 CV |

### talents：天赋

数组，每项一个天赋：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `tab` | string | 面板页签名，如「天赋1（普通攻击）」。站点括号全角半角混用，原样保留 |
| `name` | string | 天赋名 |
| `desc` | string | 天赋描述，含 `\n` 分行 |
| `icon` | string | 天赋图标地址 |
| `multipliers` | object | 倍率表，键为 `header`（表头数组，首列是属性名、其余是 `LV1`…`LVn`）与 `rows`（二维数组，第一行数据对应 `LV1`） |

### constellations：命之座

数组，每项含 `name`、`desc`、`icon`，按命座顺序排列。133 条满 6 条；埃洛伊站点只给 1 条；2 个「奇偶」词条没有此项。

### ascension：突破材料

数组，每项一个等级节点：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `level` | string | 节点名，如「1级属性/突破所需材料」「20级突破」「90级属性」。两个「奇偶」词条没有突破节点，只有「20级属性」…「100级属性」 |
| `materials` | array | 所需材料，每项 `name` 名称、`count` 数量、`id` 材料词条 content_id、`icon` 图标地址 |
| `attrs` | object | 该节点的属性快照。突破节点用「突破前X / 突破后X」成对键，等级属性节点用「X」单键 |

`attrs` 的键为中文属性名，如 `生命值`、`攻击力`、`防御力`、`暴击率`、`暴击伤害`、`元素精通`、`元素充能`、`治疗加成`、`受治疗加成`，以及 `冰元素伤害加成` 这类元素伤害加成。突破节点还会出现 `备注1` / `备注2`（角色特训等额外加成说明，如旅行者「使用罐装知识后，基础攻击力+3」）、`解锁新天赋`、`突破条件`。

### recommend：推荐装备

数组，通常是两项：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `tab` | string | 「武器推荐」或「圣遗物推荐」 |
| `header` | array | 表头，正常为 `["推荐武器", "推荐理由"]` 或 `["推荐圣遗物", "推荐理由"]` |
| `rows` | array | 二维数组，与 `header` 逐列对应 |

136 条角色有此项（各两个页签），无一缺失。站点没给表头的表格，`header` 会写成 `["列1", "列2"]` 这样的占位列名——角色数据里有 20 处。

### relations：角色关联语音

数组，每项一个页签。数据里只见到「角色关联语音」一种：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `tab` | string | 页签名 |
| `header` | array | 表头，形如 `["角色", "关于七七…"]`，第二列是对方角色名 |
| `rows` | array | 二维数组，每行 `[说话的角色名, 语音内容]` |

57/136 条角色有此字段，其余没有。

### voices：语音

对象，键是语言名（`汉语` / `日语` / `英语` / `韩语`），数组元素为：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 语音标题，如「初次见面…」「闲聊·松弛」 |
| `content` | string | 语音文本 |
| `audio` | string | 音频文件原始地址（`.mp3`），**不下载到本地** |

只包含 `voice_languages` 配置里列出的语言，默认只有 `汉语`。120/136 条角色有语音，16 条（14 条旅行者与 2 个「奇偶」）没有。

### stories：角色故事

对象，键为 `角色故事1` … `角色故事5`，值为故事正文。能解锁几条给几条：120 条角色有 5 段，14 条旅行者只有 3 段，2 个「奇偶 / 旅行者」没有。

### extras：更多资料

对象，中文键：

| 键 | 含义 |
| --- | --- |
| `角色详细` | 角色详细介绍长文 |
| `更多描述` | 补充设定 |
| `特殊料理` | 角色特色料理，格式为「名称：…\n使用效果：…」 |
| `生日邮件` | 生日邮件正文 |
| `回答` | 个别角色（丝柯克）才有的一段问答式补充 |

### displays：展示素材

数组，词条「角色展示」面板的全部条目：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 页签名，如「角色待机一」「普通攻击」「元素战技」，老角色也可能直接用角色名 |
| `image` | string | 图片或动图原始地址。**多数是 `.gif`**，只有一张是静态图，即 `portrait` 取用的那张 |

## 武器

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id |
| `name` | string | 武器名 |
| `type` | string | 武器类型，如「弓」 |
| `url` | string | 词条页地址 |
| `rarity` | int | 稀有度星级 |
| `icon` | string | 图标原始地址 |
| `skill` | object | 武器技能，见下 |
| `desc` | string | 风味文本（武器故事）。**开头带 `>\n`**，是站点富文本的引用标记，未清洗。252 条中 241 条有此键，11 条低星武器站点没写 |
| `attrs` | object | 中文键。常用 `获取途径`、`冒险等阶限制`，1 条武器另有 `强化途径` |
| `growth` | array | 成长与突破档位，见下 |
| `recommend` | array | 适用角色推荐，结构同角色的 `recommend`（`tab` / `header` / `rows`），页签为「角色」。252 条中 251 条有，表头以 `["角色名称", "描述"]` 为主，也有 `["角色名称", "介绍"]`、`["推荐角色", "描述"]` 与占位的 `["列1", "列2"]` |
| `displays` | array | 突破前后形象，`name` 为「突破前」/「突破后」，`image` 多为 `.gif`。245 条有 |
| `cover` | string | 图标落盘后的相对路径 |

`skill`：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `refinement` | string | 精炼档位说明，固定为「精炼(1/2/3/4/5)阶」 |
| `name` | string | 技能名 |
| `desc` | string | 技能描述，同一句里用 `(20%/25%/30%/35%/40%)` 的形式并列五个精炼档的数值 |

`growth` 每项一个档位，多数武器是 `1级` / `20级` / `40级` / `50级` / `60级` / `70级` / `80级` / `90级` 共 8 档（241 条），10 条只到 `70级`；「星锋剑」站点用了「未强化 / 阶段1…阶段5 / 【本版本暂无法解锁】阶段6、7」这套写法：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `level` | string | 档位名 |
| `attrs` | object | 中文键。`1级` 有 `初始基础数值`、`平均每级提升`；升档节点有 `基础数值`、`强化追加属性`、`强化描述`、`追加属性效果提升`、`解锁新天赋`、`武器等级` |
| `materials` | array | 该档位突破材料，结构同角色的材料条目（`name` / `count` / `id` / `icon`）。`1级` 没有此键 |

## 圣遗物

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id |
| `name` | string | 套装名 |
| `url` | string | 词条页地址 |
| `summary` | string | 卡片摘要。**多数与 `name` 相同**，22 条带版本前缀，如「3.3版本圣遗物 乐园遗落之花」 |
| `icon` | string | 套装图标原始地址 |
| `rarity` | string | 稀有度，原文为「4星/5星」这样的文本，**不是 int**。取值有「1星/2星/3星」「3星/4星」「4星/5星」三种 |
| `set_effects` | object | 套装效果，键为 `2件套效果` / `4件套效果`，早期的「祭X之人」四套另有 `1件套效果` |
| `attrs` | object | 中文键，目前只有 `获取途径` |
| `pieces` | object | 五个部位，键为 `生之花` / `死之羽` / `时之沙` / `空之杯` / `理之冠`，见下 |
| `recommend` | array | 推荐页签，见下 |
| `cover` | string | 图标落盘后的相对路径 |

`pieces` 的每个部位：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 该部位圣遗物名 |
| `desc` | string | 一句话描述 |
| `story` | string | 该部位的故事长文 |
| `icon` | string | 该部位图标地址 |

59 条套装五个部位齐全；另外 4 条早期套装（「祭冰之人」等）站点只写了 1 个部位。

`recommend` 为数组，固定两个页签：`角色推荐`（`header` 为 `["角色名称", "推荐原因", "词缀搭配"]`）与 `圣遗物成长数据`。

## 敌人

### 基础

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id |
| `name` | string | 敌人名，取词条正文的正式名 |
| `card_name` | string | 列表卡片上的标题。**仅当与 `name` 不同才出现** |
| `url` | string | 词条页地址 |
| `summary` | string | 卡片摘要，多为称号或一句话（如「实习雕刻师但是武道大成」） |
| `type` | string | 类型取「类型」标签，只有 `普通`（210 条）/ `精英`（127 条）/ `BOSS`（80 条）三种 |
| `elements` | array | 元素，取「元素」标签。367 条挂一个，47 条挂多个（最多 8 个），3 条没挂 |
| `attack_types` | array | 攻击方式，取「攻击方式」标签：`近战` / `远程` / `混合`。415 条挂一个，1 条挂两个 |
| `icon` | string | 卡片图标原始地址 |
| `cover` | string | 图标落盘后的相对路径 |

### basic：档案

中文键，来自词条顶部的基础信息面板：`元素`（原文写法，如「冰、风」，与 `elements` 的顺序可能不同）、`攻击方式`（招式名顿号连写）、`所在区域`。388/417 条有此键；少数另有 `元素增幅`、`攻击元素`、`盾牌元素`。

### skills：招式

数组，417 条都有。每项一招：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 招式名 |
| `image` | string | 招式动图原始地址（多为 `.gif`），**不下载到本地** |

### drops：掉落物

数组，383 条有（34 条站点没填掉落）。每项同材料条目：`name` 名称、`count` 数量、`id` 材料词条 content_id、`icon` 图标地址。`count` 为 0 表示站点只列了物品、没写数量（稀有掉落多半如此，383 条里 382 条至少有一个这样的物品）。

### guide / story：打法与背景

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `guide` | string | 攻略方法长文，含机制说明与应对要点。417 条都有 |
| `story` | string | 背景故事。395 条有 |

### stats：数据参考

数组，417 条都有。每项一档战役或等级：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `tab` | string | 档位名。常见 `正常`（340 条只有一档），另有 `幽境危战·烁煌之役`、`绝境攻练` 等 |
| `attrs` | object | 中文键。最常见 `生命值` / `相对生命值` / `抗性信息`；也有把等级写进键名的，如 `世界8(93级)`、`深境螺旋12层`、`难度IV(90级)` |
| `notes` | object | 脚注，`{"1": "本数据为实际测算模拟得出……"}`。`attrs` 里的 `[1]` `[3]` 标记按编号在这里取原文注释 |

### locations：位置导览

数组，111 条有。每项：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `tab` | string | 页签，多为 `大世界`，站点未命名的写 `默认标题` |
| `attrs` | object | 中文键：`路线说明` / `位置简述` |
| `images` | array | 说明里嵌的配图地址，去重后按出现顺序 |

### galleries：展示图

数组，14 条有。每项 `name`（页签名）+ `image`（图片地址）。

## 食物

### 基础

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id |
| `name` | string | 菜名 |
| `card_name` | string | 卡片标题。**仅当与 `name` 不同才出现** |
| `url` | string | 词条页地址 |
| `summary` | string | 卡片摘要。站点普遍写成「<菜名>介绍」这种纯占位，**这类不收录**，所以 323 条里只有 141 条有此键（多为带特殊料理说明的） |
| `types` | array | 菜系，取「食物类型」标签：`回复类` 94、`攻击类` 50、`体力类` 43、`暴击类` 39、`复活类` 37、`防御类` 36、`合成药剂` 16、`特殊食物` 12、`治疗加成` 10、`生命上限` 7。20 道菜同时挂两类 |
| `rarity` | int | 菜品星级 1-5，取「食物星级」标签（四星 → 4）。标成「其他」的 5 道没有此键 |
| `sources` | array | 获取方式，取「食物获取方式」标签：`NPC购买` 180、`其他` 64、`任务获取` 56、`宝箱获取` 23 |
| `special_dish` | bool | 是否产出角色特殊料理，取「是否产出特殊料理」标签。285 条有此键 |
| `icon` | string | 卡片图标原始地址 |
| `cover` | string | 图标落盘后的相对路径 |

### variants：品级

数组，323 条都有，合计 1032 个品级。一道菜在词条里按品级逐个录入，顺序即词条里的顺序：奇怪的 X / X / 美味的 X，有特殊料理的再接一个（名字与菜名无关，如「莫尔斯果酿」的特殊料理叫「鳞光咏叹调」）。每项：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 品级名 |
| `desc` | string | 描述 |
| `rarity` | int | 该品级星级 |
| `icon` | string | 成品图原始地址 |
| `attrs` | object | 中文键：`使用效果`（回血量、增益数值等）、`获得方式`、`食谱获得`。个别条目写成 `配方解锁`、`获得方法` |
| `ingredients` | array | 配方材料：`name` / `count` / `id` / `icon`，`id` 是材料词条 content_id。59 个品级站点没写配方（多为活动或商店直购） |

### extra：补充说明

数组，5 条有。折叠面板里的额外文字，每项 `name`（面板名，可能为空）+ `text`。

## 书籍

### 基础

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id |
| `name` | string | 书名 |
| `card_name` | string | 卡片标题。**仅当与 `name` 不同才出现** |
| `url` | string | 词条页地址 |
| `summary` | string | 卡片摘要，多数与 `name` 相同，也可能是简称（「望月者的摹刻」的摘要是「望月」） |
| `types` | array | 书籍类型，取「书籍类型」标签：`小说故事` 36、`学术作品` 13、`诗歌哲学` 13、`童话寓言` 11、`民俗传说` 9、`书信日志` 6、`手册指南` 3。4 条没挂 |
| `sources` | array | 获取方式，取「获取方式」标签：`地图探索` 50、`NPC购买` 27、`任务获取` 13。77 条有，其中 11 条挂两种、1 条挂三种 |
| `icon` | string | 卡片图标原始地址 |
| `cover` | string | 图标落盘后的相对路径 |

### volumes：分卷

数组，93 条都有，合计 295 卷（1-12 卷不等）。每项：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `title` | string | 正文面板的卷名，如 `第一卷`、`上本`、`昆图尔的故事`；站点把所有小节塞进同一面板时统一叫 `书籍内容`。没有对应正文面板时无此键 |
| `name` | string | 词条里写的书名，如 `至冬国通史·卷一`；单卷本通常就是书名本身 |
| `rarity` | int | 该卷星级 |
| `desc` | string | 该卷简介 |
| `author` | string | 作者，116 卷有 |
| `content` | string | 整卷全文，294 卷有——「丘丘语诗歌试作·（待补充）」那卷站点本身还没写 |
| `attrs` | object | 站点另挂的杂项标签，目前只有 1 卷的 `用途`（站点把「作者」误写了字段名） |

卷信息与正文在词条里是两套组件、分开存放，排列顺序互不相干（卷信息可能按「卷一、卷四、卷二、卷三」排，正文面板又是另一种顺序），卷名写法也有「卷一 / 第一卷 / 卷三 / 其之一 / 上本」几种。产物按以下顺序对齐后，再按卷序（序 0、上本 1、中本 2、下本 3、第 N 卷 10+N）重排：

1. 卷名全等（去掉空白与书名号后比对）
2. 书名末尾的小节名与正文首行（「绝云记闻·石兽」对正文的「——石兽——」）
3. 卷序（「卷一」对「第一卷」）
4. 以上都排不满且两边数量相等时，按出现顺序

## 通用图鉴（其余 20 类）

快捷导航上的其余频道（材料 / 家具 / 秘境 / 成就 / 名片 / 卡牌 / 影音回廊……）
信息密度比前六类低，正文都是同一套组件的不同组合，产物走统一结构：**顶层放
条目的检索字段，正文按站点顺序进 `sections`**。前六类的专用键名不适用于此节。

### 顶层字段

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id |
| `name` | string | 词条正式名，取正文标题 |
| `card_name` | string | 列表卡片标题。**仅当与 `name` 不同才出现**，如卡牌频道的「杜林【角色牌】」 |
| `url` | string | 观测站词条页地址 |
| `summary` | string | 一句话简介。与 `name` 相同时不写（名片频道的摘要就是名片名） |
| `channel` | string | **仅聚合频道有**：千星奇域 / 卡牌图鉴 / 影音回廊三个频道的条目属于哪个子频道，如 `衣装套装`、`角色牌`、`过场动画` |
| `icon` | string | 主图原始地址，取物品块的图标（材料 / 头像 / 家具 / 成就等） |
| `image` | string | 主图原始地址，物品块没有图标时补（秘境立绘、名片卡面、卡牌立绘）。与 `icon` 二选一，不会同时出现 |
| `cover` | string，可为 null | 主图落盘后的相对路径。深境螺旋这类站点本身没有配图的词条为 `null` |
| `rarity` | int | 星级 / 品质，由中文「N星」摊成整数；认不出的写法（如「无」）不写该键 |
| `desc` | string | 条目描述，取物品块的「描述」栏 |
| `attrs` | object | 中文键，物品块的其余「标签-值」行，如材料「用途」、卡牌「充能」 |
| `note` | object | 物品块的材料栏，见下 |

筛选标签按分类映射成英文键，取值规则分三种：单个字符串、字符串数组（一格能挂
多个标签时，如材料的多个「获取方式」）、布尔（原文「是 / 否」「有 / 无」）。
**卡片上没挂的标签整个键不写**。

| 分类 | 键 | 含义 |
| --- | --- | --- |
| 灰眸图鉴 | `types` | 类型，如「「灰眸」讯息」「臻冰造物图鉴」 |
| 组织图鉴 | `regions` | 地区，如「至冬」「跨国家」 |
| 头像图鉴 | `category` | 头像 / 头像框 |
| 材料图鉴 | `types` / `sources` / `rarity` | 道具类型 / 获取方式 / 星级 |
| 家具图鉴 | `zones` / `types` / `rarity` / `sources` / `blueprint_sources` | 室内外 / 摆件类型 / 品质 / 摆设获取方式 / 图纸获取方式 |
| 秘境图鉴 | `types` / `elements` / `cost` / `coop` / `quest_domain` | 秘境类型 / 推荐元素 / 消耗 / 是否可联机 / 是否任务本 |
| NPC与商店图鉴 | `regions` / `types` / `specials` / `dialogue_reward` / `card_challenge` | 地区 / 类型 / 特殊效果 / 有对话奖励 / 有牌手挑战 |
| 成就图鉴 | `set` / `version` / `daily_commission` / `hidden` | 成就集 / 上线版本 / 每日委托成就 / 隐藏成就 |
| 活动图鉴 | `types` / `versions` | 活动类型 / 版本 |
| 任务图鉴 | `types` / `regions` / `versions` | 任务类型 / 任务区域 / 版本号 |
| 动物图鉴 | `types` / `catchable` | 动物类型 / 是否可捕获 |
| 幻想真境剧诗图鉴 | `types` | 类别 |
| 冒险家协会图鉴 | `types` / `regions` / `has_achievement` | 委托类型 / 区域 / 有无成就 |
| 名片图鉴 | `types` | 名片类型 |
| 千星奇域图鉴 | `types` / `parts` / `gender` / `tier` / `colors` / `sources` / `shape_sources` | 类别 / 部位 / 适用性别 / 品阶 / 色系 / 获取方式 / 形录获取方式 |
| 卡牌图鉴 | `types` / `tags` / `elements` / `weapon_types` / `factions` / `cost` / `modes` | 类型 / 标签 / 元素 / 武器 / 阵营 / 花费 / 特殊模式 |
| 影音回廊图鉴 | `types` / `regions` / `albums` / `music_types` / `bpm_range` / `countries` | 类型 / 区域 / 专辑 / 乐曲分类 / 每分钟节拍数范围 / 所属国家 |

深境螺旋、幽境危战、考据三类在卡片上没有筛选标签，只有公共字段与 `sections`。

### note：材料栏

物品块有「材料栏」时收录（家具的「制作材料」、成就的「名片纹饰」、材料的
「获取方式」、衣装的「缤纷评分」）。站点把标签与值放在同一个「标签-值」对里，
标签各频道写法不同，原样保留：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `label` | string | 材料栏的标签，如「制作材料」「名片纹饰」 |
| `text` | string | 材料栏纯文本 |
| `entries` | array | 栏里引用的词条，每项 `name` / `count`（数量）/ `id`（词条 id）/ `icon` |

### sections：正文区块

数组，按站点顺序排列，每块以 `kind` 标明类型、`tab` 是站点给这一块起的模块名
（如「秘境详情」「成就列表」）。相邻且 `kind` + `tab` 相同的区块会合并成一段，
避免站点重复挂载的内容（任务频道的「任务概述」常被挂三次）在产物里重复。

| `kind` | 载荷 | 出现在 |
| --- | --- | --- |
| `info` | `attrs`（中文键「标签-值」）/ `name` / `image` / `rarity` / `life` / `energy` / `gold_image` | 秘境、家具、NPC、卡牌、活动、任务、深境螺旋 |
| `text` | `text`（长文）/ `images` / `videos`（`url` + `poster`） | 组织、考据、过场动画、NPC 对话说明、任务过程 |
| `table` | `tables`（`tab` / `header` / `rows`）/ `options`（字段取值）/ `images` | 成就、秘境、活动、深境螺旋、原神 OST |
| `gallery` | `items`（`tab` / `image`） | 家具、秘境位置、NPC 展示、名片 |
| `skills` | `items`（`name` / `type` / `icon` / `life` / `energy` / `desc`） | 卡牌的角色牌与魔物牌 |
| `levels` | `items`（`tab` / `attrs` / `notes` / `target` / `desc` / `first_half` / `second_half`） | 幽境危战、深境螺旋 |
| `timeline` | `items`（`tab` / `attrs` / `images`） | 组织的重要事件 |
| `dialogue` | `lines`（`option` / `text` / `icon`） | 灰眸讯息、NPC 对话、活动彩蛋 |
| `voice` | `languages`（语言 → `name` / `text` / `audio`） | 影音回廊的「角色语音展示」 |
| `links` | `items`（`name` / `cover` / `link`） | 活动的「攻略推荐」 |

`levels` 有两种形态，靠键名区分：幽境危战给 `attrs`（挑战条件）与 `notes`
（`[1]` 脚注正文），深境螺旋给 `target`（通关目标）与 `first_half` / `second_half`
（上下半各轮次的敌人，每项带 `entries`）。
