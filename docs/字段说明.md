# 字段说明

三类图鉴 JSON 的键名一览。顶层结构与公共字段在前，各分类专有字段在后。

## 通用约定

- **英文键**是项目自己定的语义化键名，含义固定，跨版本不变；**中文键**是观测枢词条原文的表格行标题，原样保留，随站点内容变化，不做翻译。
- 标题带「预告」的未上线词条（如「米提亚【预告】」）正文全是「待更新」占位，直接跳过不导出，不占条目数。
- 可选键在数据不存在时**整个键不出现**，不会写成 `null` 或空串（`cover` 例外，见下）。
- 图片字段分两类：`icon` / `portrait` / `image` / `audio` 是站点原始 URL；`cover` 是落盘后的相对路径，分隔符随操作系统。
- 文本字段里的换行原样保留（`\n`），未做 HTML 转义。

## 文件级

`角色图鉴.json` / `武器图鉴.json` / `圣遗物图鉴.json` 三者结构一致：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `catalog` | string | 分类中文名，如「角色图鉴」 |
| `count` | int | 本分类条目数，等于 `items` 数组长度 |
| `generated_at` | string | 生成时间，`YYYY-MM-DD HH:MM:SS` 本地时区 |
| `items` | array | 条目数组。角色与武器按稀有度降序、同稀有度按名称排；圣遗物 `rarity` 是文本，只按名称排 |

`manifest.json`：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `checked_at` | string | 本轮检查时间 |
| `generated_at` | string | 产物生成时间 |
| `catalogs` | array | 各分类的 `key`、`name`、`count`、`file`（产物文件名，未重写时带「（未变）」后缀）、`failed`（失败明细数组） |

`changes.json`：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `checked_at` | string | 本轮检查时间 |
| `totals` | object | 全分类汇总，键见下 |
| `catalogs` | array | 各分类明细，每项带 `key`、`name` 与同样的计数键 |

计数键：`added` 新增、`updated` 更新、`removed` 移除、`failed` 失败、`unchanged` 未变、`skipped` 跳过。

## 角色

### 基础

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id，可用于拼 `url` |
| `name` | string | 角色名，取词条正文的正式名 |
| `card_name` | string | 列表卡片上的标题。**仅当与 `name` 不同才出现**，典型是旅行者：`name` 为「旅行者（空）」、`card_name` 为「旅行者·冰」 |
| `url` | string | 观测枢词条页地址 |
| `summary` | string | 一句话简介 |
| `alias` | string | 别名 / 曾用名。站点未提供该字段，实际数据中不出现 |
| `region` | string | 地区，如「璃月港」 |
| `element` | string | 元素，如「冰」 |
| `weapon_type` | string | 武器类型，如「弓」 |
| `rarity` | int | 稀有度星级，4 或 5；两个「奇偶」词条站点给 0 |
| `icon` | string | 列表页头像原始地址（196×196）。**不再下载到本地**，仅保留地址 |
| `portrait` | string | 立绘原始地址，取词条「角色展示」面板里唯一的静态图 |
| `cover` | string，可为 null | 立绘落盘后的相对路径。**唯一会显式为 `null` 的键**：两个「奇偶」词条没有立绘时为 `null` |

### basic：档案

中文键，取值直接来自词条档案面板，常见键：

| 键 | 含义 |
| --- | --- |
| `生日` | 角色生日，如「12月2日」 |
| `所属` | 所属组织 / 势力 |
| `定位` | 玩法定位，如「冰元素输出型角色」 |
| `武器类型` | 与顶层 `weapon_type` 同值，此处为原文写法 |
| `命之座` | 命之座名称，如「仙麟座」 |
| `称号` | 角色称号 |
| `角色定位` | 少数角色（千星奇域的两个「奇偶」）用这个键代替 `定位` |
| `神之眼` | 神之眼属性。旅行者 14 条与「奇偶」2 条为「无」，北斗、辛焱、香菱为对应元素名 |

### cv：配音

四个中文键，值为配音演员名（原文含非拉丁名时会带括号注音）。134 条角色四个都有，2 个「奇偶」词条站点没给 CV、无此键：

| 键 | 含义 |
| --- | --- |
| `中` | 汉语 CV |
| `日` | 日语 CV |
| `英` | 英语 CV |
| `韩` | 韩语 CV |

### talents：天赋

数组，每项一个天赋：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `tab` | string | 面板页签名，如「天赋1（普通攻击）」。站点括号全角半角混用，原样保留 |
| `name` | string | 天赋名 |
| `desc` | string | 天赋描述，含 `\n` 分行 |
| `icon` | string | 天赋图标地址 |
| `multipliers` | object | 倍率表，键为 `header`（表头数组，首列是属性名、其余是 `LV1`…`LVn`）与 `rows`（二维数组，第一行数据对应 `LV1`） |

### constellations：命之座

数组，每项含 `name`、`desc`、`icon`，按命座顺序排列。133 条满 6 条；埃洛伊站点只给 1 条；2 个「奇偶」词条没有此项。

### ascension：突破材料

数组，每项一个等级节点：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `level` | string | 节点名，如「1级属性/突破所需材料」「20级突破」「90级属性」。两个「奇偶」词条没有突破节点，只有「20级属性」…「100级属性」 |
| `materials` | array | 所需材料，每项 `name` 名称、`count` 数量、`id` 材料词条 content_id、`icon` 图标地址 |
| `attrs` | object | 该节点的属性快照。突破节点用「突破前X / 突破后X」成对键，等级属性节点用「X」单键 |

`attrs` 的键为中文属性名，如 `生命值`、`攻击力`、`防御力`、`暴击率`、`暴击伤害`、`元素精通`、`元素充能`、`治疗加成`、`受治疗加成`，以及 `冰元素伤害加成` 这类元素伤害加成。突破节点还会出现 `备注1` / `备注2`（角色特训等额外加成说明，如旅行者「使用罐装知识后，基础攻击力+3」）、`解锁新天赋`、`突破条件`。

### recommend：推荐装备

数组，通常是两项：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `tab` | string | 「武器推荐」或「圣遗物推荐」 |
| `header` | array | 表头，正常为 `["推荐武器", "推荐理由"]` 或 `["推荐圣遗物", "推荐理由"]` |
| `rows` | array | 二维数组，与 `header` 逐列对应 |

136 条角色有此项（各两个页签），无一缺失。站点没给表头的表格，`header` 会写成 `["列1", "列2"]` 这样的占位列名——角色数据里有 20 处。

### relations：角色关联语音

数组，每项一个页签。数据里只见到「角色关联语音」一种：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `tab` | string | 页签名 |
| `header` | array | 表头，形如 `["角色", "关于七七…"]`，第二列是对方角色名 |
| `rows` | array | 二维数组，每行 `[说话的角色名, 语音内容]` |

57/136 条角色有此字段，其余没有。

### voices：语音

对象，键是语言名（`汉语` / `日语` / `英语` / `韩语`），数组元素为：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 语音标题，如「初次见面…」「闲聊·松弛」 |
| `content` | string | 语音文本 |
| `audio` | string | 音频文件原始地址（`.mp3`），**不下载到本地** |

只包含 `voice_languages` 配置里列出的语言，默认只有 `汉语`。120/136 条角色有语音，16 条（14 条旅行者与 2 个「奇偶」）没有。

### stories：角色故事

对象，键为 `角色故事1` … `角色故事5`，值为故事正文。能解锁几条给几条：120 条角色有 5 段，14 条旅行者只有 3 段，2 个「奇偶 / 旅行者」没有。

### extras：更多资料

对象，中文键：

| 键 | 含义 |
| --- | --- |
| `角色详细` | 角色详细介绍长文 |
| `更多描述` | 补充设定 |
| `特殊料理` | 角色特色料理，格式为「名称：…\n使用效果：…」 |
| `生日邮件` | 生日邮件正文 |
| `回答` | 个别角色（丝柯克）才有的一段问答式补充 |

### displays：展示素材

数组，词条「角色展示」面板的全部条目：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 页签名，如「角色待机一」「普通攻击」「元素战技」，老角色也可能直接用角色名 |
| `image` | string | 图片或动图原始地址。**多数是 `.gif`**，只有一张是静态图，即 `portrait` 取用的那张 |

## 武器

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id |
| `name` | string | 武器名 |
| `type` | string | 武器类型，如「弓」 |
| `url` | string | 词条页地址 |
| `rarity` | int | 稀有度星级 |
| `icon` | string | 图标原始地址 |
| `skill` | object | 武器技能，见下 |
| `desc` | string | 风味文本（武器故事）。**开头带 `>\n`**，是站点富文本的引用标记，未清洗。252 条中 241 条有此键，11 条低星武器站点没写 |
| `attrs` | object | 中文键。常用 `获取途径`、`冒险等阶限制`，1 条武器另有 `强化途径` |
| `growth` | array | 成长与突破档位，见下 |
| `recommend` | array | 适用角色推荐，结构同角色的 `recommend`（`tab` / `header` / `rows`），页签为「角色」。252 条中 251 条有，表头以 `["角色名称", "描述"]` 为主，也有 `["角色名称", "介绍"]`、`["推荐角色", "描述"]` 与占位的 `["列1", "列2"]` |
| `displays` | array | 突破前后形象，`name` 为「突破前」/「突破后」，`image` 多为 `.gif`。245 条有 |
| `cover` | string | 图标落盘后的相对路径 |

`skill`：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `refinement` | string | 精炼档位说明，固定为「精炼(1/2/3/4/5)阶」 |
| `name` | string | 技能名 |
| `desc` | string | 技能描述，同一句里用 `(20%/25%/30%/35%/40%)` 的形式并列五个精炼档的数值 |

`growth` 每项一个档位，多数武器是 `1级` / `20级` / `40级` / `50级` / `60级` / `70级` / `80级` / `90级` 共 8 档（241 条），10 条只到 `70级`；「星锋剑」站点用了「未强化 / 阶段1…阶段5 / 【本版本暂无法解锁】阶段6、7」这套写法：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `level` | string | 档位名 |
| `attrs` | object | 中文键。`1级` 有 `初始基础数值`、`平均每级提升`；升档节点有 `基础数值`、`强化追加属性`、`强化描述`、`追加属性效果提升`、`解锁新天赋`、`武器等级` |
| `materials` | array | 该档位突破材料，结构同角色的材料条目（`name` / `count` / `id` / `icon`）。`1级` 没有此键 |

## 圣遗物

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 词条 content_id |
| `name` | string | 套装名 |
| `url` | string | 词条页地址 |
| `summary` | string | 卡片摘要。**多数与 `name` 相同**，22 条带版本前缀，如「3.3版本圣遗物 乐园遗落之花」 |
| `icon` | string | 套装图标原始地址 |
| `rarity` | string | 稀有度，原文为「4星/5星」这样的文本，**不是 int**。取值有「1星/2星/3星」「3星/4星」「4星/5星」三种 |
| `set_effects` | object | 套装效果，键为 `2件套效果` / `4件套效果`，早期的「祭X之人」四套另有 `1件套效果` |
| `attrs` | object | 中文键，目前只有 `获取途径` |
| `pieces` | object | 五个部位，键为 `生之花` / `死之羽` / `时之沙` / `空之杯` / `理之冠`，见下 |
| `recommend` | array | 推荐页签，见下 |
| `cover` | string | 图标落盘后的相对路径 |

`pieces` 的每个部位：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 该部位圣遗物名 |
| `desc` | string | 一句话描述 |
| `story` | string | 该部位的故事长文 |
| `icon` | string | 该部位图标地址 |

59 条套装五个部位齐全；另外 4 条早期套装（「祭冰之人」等）站点只写了 1 个部位。

`recommend` 为数组，固定两个页签：`角色推荐`（`header` 为 `["角色名称", "推荐原因", "词缀搭配"]`）与 `圣遗物成长数据`。
